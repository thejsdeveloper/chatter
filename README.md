# Chatter: CSV FAQ Agent

A small Streamlit app. Upload one or more CSV files, ask a question in plain English, and get an answer built only from the data in those files. If the answer isn't there, Chatter says so.

Built with Streamlit, pandas, LangChain's pandas DataFrame agent and `gpt-4o-mini` (temperature 0), called through **OpenRouter** by default (OpenAI directly is also supported).

## Run

```bash
uv sync
cp .env.example .env        # then set OPENROUTER_API_KEY (or OPENAI_API_KEY)
uv run streamlit run app.py
```

Pick the provider in the sidebar. If no key is found in `.env`, the app asks for one there. Set `CHATTER_MODEL` or edit the Model field to try another OpenRouter model; it must support tool calling.

Sample CSVs are in `data-sources/` (e-commerce FAQs, credit card terms, hospital policy, SaaS docs).

## Files

- `agent.py`: the system prompt, the LLM setup and the pandas agent (no UI code)
- `app.py`: the Streamlit UI (upload, preview, chat)

> The agent runs pandas code generated by the model on your machine (`allow_dangerous_code=True`). Use it only with trusted data, locally.
